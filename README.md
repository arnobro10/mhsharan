# Md Mahbub Ul Hassan Sharan — Portfolio

A responsive academic portfolio covering environmental social science, climate migration, adaptation, WASH, and quality of life.

## Pages

- `index.html`: introduction, affiliations, research themes, featured grant, and writing highlights.
- `research.html`: research areas, grants, and selected recent work.
- `writings.html`: creative work and full expandable publication text.
- `teaching.html`: teaching role, courses, and topics.
- `resume.html`: experience, education, awards, certifications, and languages.
- `assets/cv.pdf`: downloadable academic CV.

## Preview

Run `python -m http.server 8766` from this folder, then open http://localhost:8766.

## GitHub Pages

This is a static website with no build step. Configure GitHub Pages to deploy from the `main` branch and `/ (root)` folder. Relative links support project hosting at `/mhsharan/`.

## Content

Content and existing photos were migrated from https://mhsharan.github.io/. The original teaching material links were empty; these are explicitly marked unavailable rather than linked to missing files. External creative writing and photography portfolios remain linked.
